# テックブログのCMSを作成中
以前から細々と更新していたテックブログのCMSですが、最近のAIコーディングエージェントの発達もあり、</br>
より更新時の不具合やエラーへの遭遇が減ったことで俄然モチベーションが上がりました。
ということで、直近少しペースを上げてCMSサイトの作成を行っています。

普段からあまりコーディングはせず面倒くさがりですが、それなりに頑張ったおかげもあって仕上がってきた感があります。
まだ正式なリリースまでには時間がかかりそうですが、ひとまず更新状況と実際のWebサイトだけ公開します。

* [techblog_cms](https://github.com/dendencat/techblog_cms)
* [blog.iohub.link](https://blog.iohub.link)

AI時代には自己満足で良いから、自分向けのプロダクトをうんと生産することで自分の生産性をまずは上げていきたいですね。
